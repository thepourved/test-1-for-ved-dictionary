# 📚 Veterinary Dictionary - دیکشنری دامپزشکی

یک اپلیکیشن اندروید حرفه‌ای برای دسترسی سریع به اصطلاحات دامپزشکی با ترجمه‌های دقیق.

## ✨ ویژگی‌ها

- 🔍 **جستجوی سریع و هوشمند** - جستجو در فارسی و انگلیسی
- 📚 **دسته‌بندی موضوعی** - سازمان‌دهی منطقی اصطلاحات
- 📖 **دسته‌بندی بر اساس کتاب‌ها** - مراجع تخصصی
- 🎤 **صوت تلفظ صحیح** - شنیدن تلفظ صحیح انگلیسی
- ❤️ **علاقه‌مندی‌ها** - ذخیره لغات مورد علاقه
- 📜 **سابقه جستجو** - دسترسی سریع به جستجوهای قبلی
- 👤 **حساب کاربری** - ذخیره اطلاعات و تنظیمات شخصی
- 🌙 **حالت شب** - رابط کاربری راحت برای چشم
- 📱 **UI/UX مدرن** - طراحی زیبا و کاربرپسند

## 🛠️ تکنولوژی‌ها

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Database**: Room + SQLite
- **Authentication**: Firebase Auth
- **Backend**: Firebase Firestore
- **Audio**: ExoPlayer / Media3
- **Minimum API**: 26 (Android 8.0)
- **Target API**: 34 (Android 14)

## 🚀 شروع کار

### نیازمندی‌ها
- Android Studio Arctic Fox یا جدیدتر
- JDK 11+
- Android SDK 34+

### نصب و راه‌اندازی
```bash
git clone https://github.com/thepourved/test-1-for-ved-dictionary.git
cd test-1-for-ved-dictionary
```

1. Android Studio را باز کنید
2. Project را import کنید
3. Gradle sync کنید
4. Firebase را راه‌اندازی کنید
5. اپ را Run کنید
